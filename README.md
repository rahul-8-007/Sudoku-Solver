# Sudoku Solver | Python

A Python-based Sudoku solver that solves standard 9x9 Sudoku puzzles
using recursive backtracking.

## Features
- Solves Sudoku puzzles automatically
- Validates rows, columns, and 3x3 subgrids
- Uses recursion and backtracking
- Detects puzzles with no solution
- Displays the puzzle and solution in the terminal

## Concepts Used
- Python functions
- 2D lists
- Recursion
- Backtracking
- Constraint checking

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project directory in a terminal.
4. Run:

   python sudoku_solver.py

## Input Format
Use a 9x9 grid of integers.
- Numbers 1-9 represent filled cells.
- 0 represents an empty cell.
